# breakout-final
# Breakout 打砖块游戏
基于 Raylib 开发的经典打砖块游戏，包含完整关卡、特效、道具、存档系统，纯 C++ 实现，无外部音频/资源依赖。

## 项目文件
- `main.cpp` - 游戏入口
- `Game.h` - 游戏类头文件
- `Game.cpp` - 游戏核心逻辑实现

## 功能特性
- 🎯 **4 个完整关卡**
  - 关卡 1~3：固定布局彩色砖块
  - 关卡 4：随机砖块布局（按 R 重新生成）
- 🎵 **内置音效**：碰撞、得分、通关自动生成不同音调音效
- ✨ **粒子特效**：砖块破碎时显示对应颜色粒子动画
- 🎁 **道具系统（3 种）**
  - `LONG`：延长挡板
  - `THREE`：召唤多颗小球
  - `SLOW`：减慢球速
- 💾 **自动/手动存档**：支持继续游戏
- 🎨 **实时 UI**：分数、生命值、关卡、道具状态显示

## 运行环境
- C++11 及以上
- Raylib 图形库

## 编译运行
```bash
g++ main.cpp Game.cpp -o breakout -lraylib -lm -lpthread -ldl -lrt -lX11
./breakout
```

## 操作说明
| 按键 | 功能 |
|------|------|
| ← / → | 移动挡板 |
| 空格 | 保存并返回菜单 |
| Enter | 游戏结束后返回菜单 |
| R | 关卡4重新生成砖块 |
| 鼠标点击 | 菜单选择/开始游戏 |

## 游戏规则
- 初始生命：3
- 球掉落底部扣 1 生命，生命为 0 游戏结束
- 打碎所有砖块进入下一关
- 不同颜色砖块分值不同
- 击碎砖块 30% 概率掉落道具

## 存档说明
- 自动保存：`save1.json ~ save4.json`
- 菜单显示 `CONTINUE` 表示有存档可继续

## 核心模块
- 物理碰撞与反弹
- 关卡加载与随机生成
- 粒子系统
- 道具计时系统
- JSON 进度读写
- 动态音频生成
